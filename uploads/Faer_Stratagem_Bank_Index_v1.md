# Faer_Stratagem_Bank_Index_v1

## Purpose
Optional KB-backed solution-input bank for **nontechnical contradiction resolution**.
Use only **after** contradiction/resources/stakeholders are explicit.
Do **not** use as the default front-end framing method.

## Primary source
- `Faer-Sergey_TRIZ-beyond-technology-Stratagems-as-an-analogue-of-techniques-for-solving-non-technical-problems-in-the-field-of-elections-advertising-and-PR_2012_RU.pdf`

## Activation rule
Activate only when the task is clearly nontechnical or mixed-domain, such as:
- PR / messaging / persuasion
- stakeholder conflict / narrative conflict
- positioning / campaigning / public-facing strategy
- organizational politics / influence
- reputation / framing / agenda setting

## Placement in MetaLens flow
1. Initial Situation / Target Effect
2. MPV / stakeholder framing
3. System boundary / FA / CECA / contradiction / resources
4. **Faer stratagem bank query**
5. shortlist + μTests + risk/blowback checks

## Required inputs before querying bank
- target contradiction
- key stakeholders
- available resources / constraints
- domain / context
- main risk or blowback concern

## Required outputs
- 3–7 stratagem candidates
- contradiction fit
- expected gain
- required resources
- likely side-effects / blowback
- one reversible μTest per candidate

## Do not use
- as a replacement for FA / CECA / contradictions
- as a default bank for technical engineering problems
- before the problem is structurally formulated
